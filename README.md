# SEZ GIS Indonesia

## Abstract

Governments across the developing world attempt to steer industrialization into lagging regions using fiscal incentives, and Indonesia has run this experiment at scale. Rigorous evaluation of its KAPET programme shows that tax breaks placed in remote, low-potential districts produced no measurable gains in firm entry, output, migration, or welfare, because the underlying preconditions for self-sustaining agglomeration were absent.
This project inverts that retrospective finding into a prospective, reproducible spatial instrument. Using only open geospatial data — harmonized night-time lights (1992–present), OpenStreetMap road networks, global built-up and population grids, terrain and flood layers, and satellite-derived port-activity estimates — we operationalize the theoretical preconditions for industrial agglomeration as a stack of spatial surfaces on a national grid. We then estimate, from Indonesia's own history, which precondition configuration discriminated between locations where industrial activity became self-sustaining and where it stagnated, using pre-period predictors and natural-geography instruments to break the reverse-causality problem that defeats naïve suitability models.
The fitted model is validated against KAPET as a natural experiment. Finally, we compute, for each grid cell, the residual between predicted suitability and realized agglomeration: high positive residuals identify locations under-performing their fundamentals — latent potential waiting on a missing layer — and a partial-dependence decomposition names the binding constraint at each. The result is the first fully open-data, sub-national viability surface for Indonesian industrial location, reproducible and transferable to other archipelagic and developing contexts
